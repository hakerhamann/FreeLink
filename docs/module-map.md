# Module Map

## Android

- `android:app`: app shell and composition root.
- `android:core:*`: shared platform and domain foundations.
- `android:feature:*`: user-facing feature flows.
- `android:benchmark`, `android:baselineprofile`: performance tooling modules.

## Backend

- `backend:apps:api`: REST API surface.
- `backend:apps:ws-gateway`: WebSocket gateway.
- `backend:apps:worker`: async and background processing.
- `backend:libs:*`: reusable backend domain and infrastructure libraries.
- `backend/infra/*`: Docker, migrations, seed inputs.
