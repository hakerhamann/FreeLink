# Design System

FreeLink visual language: deep dark background, cyan/purple neon accents, glow, glass surfaces.

## Base tokens

- Colors: `BgDeep`, `BgSurface`, `NeonCyan`, `NeonPurple`, `TextPrimary`, `TextSecondary`.
- Radii: card, bubble, chip.
- Spacing: xs, sm, md, lg, xl.

## Planned reusable primitives

- Privacy chip
- Glowing avatar ring
- Neon icon button
- Message bubble variants
- Reaction pill
- Search field
- Segmented filters
- Profile action tile
- Settings row
- Voice waveform UI
- Attachment tray
- Bottom navigation item
