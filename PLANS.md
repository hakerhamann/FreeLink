# FreeLink Delivery Plan

## Sprint cadence
- Sprint length: 2 weeks
- Goal: secure MVP in 8 sprints

## Sprint board

1. Sprint 0: foundation and scaffolding (completed)
2. Sprint 1: auth, devices, profile, and privacy baseline (completed)
3. Sprint 2: chat list and search (in progress)
4. Sprint 3: direct chat core
5. Sprint 4: groups and profile
6. Sprint 5: media pipeline
7. Sprint 6: privacy and archive
8. Sprint 7: stabilization and release

## Change protocol
- Each stage is merged as focused, reviewable PRs.
- Every PR must include tests or explicit test-gap notes.
- Risks and next step are documented in PR description.
