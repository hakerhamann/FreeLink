# FreeLink

Monorepo for FreeLink secure messenger (Android + Backend).

## Layout

- `android/` - Android multi-module application
- `backend/` - Ktor modular monolith
- `build-logic/` - shared Gradle convention plugins
- `docs/` - architecture and engineering docs
- `scripts/` - local automation scripts
- `.github/` - CI and repository templates

## Getting started

1. Install JDK 17.
2. Generate Gradle wrapper (`gradle wrapper`) if unavailable.
3. Run `./gradlew tasks` from repository root.
